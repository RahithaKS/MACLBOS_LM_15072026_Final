---
name: Entity P&L PowerPoint Format
description: The governing presentation structure for Entity P&L exports.
---

Entity P&L exports must render the prescribed Bosch financial-statement layout:
year-end, CF, current, comparison, variance, and percentage columns alongside
root-cause commentary and the branded footer.

**Why:** Generic template mapping treats the P&L as an arbitrary supporting
table and can collapse or reorder its financial columns, making the exported
report visibly inconsistent with the approved format.

**How to apply:** Keep Entity P&L on its dedicated Bosch-style export path.
Use generic template rendering only for non-P&L board types; adapt the
dedicated renderer when the governed P&L presentation format changes.
